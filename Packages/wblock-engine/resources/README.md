# Resources

`resources.json` is the adblock-rust `Resource` array used for `+js(...)`
scriptlets and redirects. It is generated by `build-resources.mjs` from:

- brave/adblock-resources `dist/resources.json` at commit
  `6da9b247c3368baa8b4f24cd02046e18702a6527` (MPL-2.0; 17 redirect resources).
- uBlock Origin `src/js/resources/scriptlets.js` and its imports at commit
  `f3a138cf22773f4f5efe01f63326b9ccb2acf6be` (GPL-3.0; scriptlets and helpers).
  Brave's dist has no scriptlets, so these come from uBO's sources.

Regenerate:

    node build-resources.mjs brave-dist-resources.json ublock/src/js/resources/scriptlets.js > resources.json
