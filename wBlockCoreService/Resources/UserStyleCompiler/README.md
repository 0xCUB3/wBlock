# Less compiler provenance

`less.min.js` is the browser bundle from Less 4.9.0, copied from the npm
package `less@4.9.0`. It is used offline in a fresh JavaScriptCore context;
no network, filesystem, DOM, timers, or native bridge objects are exposed and
Less inline JavaScript is disabled.
